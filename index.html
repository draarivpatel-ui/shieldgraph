      Known misses and holdout notes

      The corpus is written by the same author as the detectors, so it is a coverage check rather than an independent holdout set. The perfect Balanced score means these attack shapes are covered, not that the detector generalizes.

      • Ordinary source code can still be exfiltrated to an allowlisted host when no learned secret or credential shape is present.
      • A command assembled with printf can hide the network tool name from static shell analysis.
      • DNS rebinding is invisible because the guard never resolves hostnames. A production deployment needs a resolving egress proxy.
